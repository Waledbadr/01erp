# Design system

Read before UI work. Build accessible Button, Input, Select, DatePicker, Modal, Drawer, Toast, responsive Table/cards, Tabs, Badge, EmptyState, Skeleton, ConfirmDialog, PageHeader, and FilterBar with consistent tokens. Use semantic HTML, visible focus, labels, and keyboard navigation. Use logical CSS properties (inline-start/end, block-start/end) instead of physical left/right. Default Arabic RTL, switch English LTR instantly without reload/logout, and draw all user-facing strings from resources. Format currency, dates, and numbers by locale while storing raw exact values. Mobile workflows use intentional cards/actions, not squeezed desktop tables. Every page has loading, empty, validation, and error states. Invoices and statements use formal typography, spacing, bilingual identity, clear totals, VAT detail, and print-safe layouts.
