# دليل المستخدم — المرحلة 00

تفتح الصفحة الرئيسية حالة التأسيس وروابط صفحات الحساب. لا يمكن تسجيل الدخول أو إنشاء شركة قبل تنفيذ مرحلة الحسابات والصلاحيات؛ تظهر الصفحات الحالية وصفًا واضحًا لذلك. لتغيير اللغة، اختر «English» أو «العربية» من القائمة في أعلى الصفحة، ويُحفظ الاختيار في هذا المتصفح. على الهاتف تظهر روابط التنقل أسفل الشاشة. تعرض بطاقة حالة الخدمة نتيجة فحص اتصال قاعدة البيانات الفعلي.
