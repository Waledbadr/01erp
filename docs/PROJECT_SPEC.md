# Project specification

The master scope is defined in ../00-MASTER-SYSTEM-PROMPT.md and phase requirements in the numbered root files. Implement one phase at a time. The initial platform serves one company while isolating all company-owned records for future multi-tenancy. The ledger is the financial source of truth, inventory is source-linked, and Arabic and English are first-class locales. Phase-specific acceptance criteria belong in task files and PHASE_STATUS.md.
